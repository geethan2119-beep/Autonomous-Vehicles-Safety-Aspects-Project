# Autonomous-Vehicles-Safety-Aspects-Project
Conducted an in-depth exploratory data analysis of autonomous vehicle (AV) crashes using NHTSA and DMV datasets, examining crash patterns, sensor limitations, road conditions, weather, and disengagement scenarios. Evaluated ADAS levels, sensor technologies (LiDAR, Radar, Cameras, Ultrasonic), and identified operational challenges like calibration issues, poor weather performance, and infrastructure-related failures. Performed statistical analysis on crash severity, contact areas, reaction times, and correlations between autonomous miles traveled and crash frequency, uncovering key safety trends in AV systems. Analyzed public sentiment before and after major AV crashes using Twitter data and VADER sentiment analysis, identifying significant negative shifts in public perception following high-profile incidents.
